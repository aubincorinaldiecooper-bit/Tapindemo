# Tap In

Tap In: the party app (Classic and "I Betchu Won't" modes).

Built with React, TypeScript, Vite, Tailwind CSS and [Motion](https://motion.dev) for micro-interactions.

## Run locally

```bash
npm install
npm run dev
```

Other scripts: `npm run build`, `npm run lint`, `npm run preview`.

## Status

Prototype. Rooms, payments and lives are not wired to a backend yet; the game runs on a single device.
